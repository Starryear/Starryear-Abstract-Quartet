# Starryear-Abstract-Quartet

由 **Starryear** 创作的可安装摄影影像 Skill。

将一张原始照片转译为四个连续阶段：

**现实 → 记忆 → 抽象 → 再解释**

## 下载 Skill

[下载 Starryear-Abstract-Quartet-Skill.zip](./Starryear-Abstract-Quartet-Skill.zip)

下载 ZIP 后，在支持 Skills 的 Codex 中安装；也可以下载整个仓库，Skill 的入口文件是 [SKILL.md](./SKILL.md)。

## 四联结构

1. 原始证据｜Original Evidence
2. 记忆转译｜Starryear Memory Translation
3. 结构提纯｜Starryear Structural Distillation
4. 余像融合｜Starryear Afterimage Fusion

四幅等高的 2:1 横向画面上下排列，最终组成 1:2 竖版作品。无边框、无标签、无文字、无 Logo。

## 文件

- `SKILL.md` — 核心调用说明
- `agents/openai.yaml` — Skill 显示名称与默认提示
- `references/four-panel-method.md` — 完整四联方法
- `Starryear-Abstract-Quartet-Skill.zip` — 可直接下载的安装包
- `index.html` — 辅助作品展示网站
