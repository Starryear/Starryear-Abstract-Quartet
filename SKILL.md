# Starryear-Abstract-Quartet

Create one finished vertical artwork from one source photograph. Treat all four panels as stages of the same remembered place:

`reality → memory → abstraction → reinterpretation`

Read [references/four-panel-method.md](references/four-panel-method.md) before generating the artwork. Treat it as the complete art-direction specification, including its correction rules.

## Workflow

1. Inspect the supplied photograph and complete the visual-evidence analysis in the reference. Lock the scene anchors before generating anything.
2. Choose one 2:1 landscape framing with the smallest useful crop. Protect the main subject and visual balance. Use that exact spatial frame as the basis of all four panels.
3. Create Panels 2, 3, and 4 as separate interpretations. Do not ask an image generator to create the finished four-panel sheet in one pass.
4. Build the panels in this order:
   - Panel 1 — Reality: preserve the source photograph faithfully. Do not regenerate, redraw, filter, recolor, retouch, or add objects.
   - Panel 2 — Memory: translate the scene into a restrained editorial visual memory while preserving its photographic origin, light, structure, and mood.
   - Panel 3 — Abstraction: analyze and reconstruct the scene as a minimal structural study with clean geometry and reduced detail.
   - Panel 4 — Reinterpretation: fuse the emotional memory of Panel 2 with the spatial discipline of Panel 3. It should feel like a real place remembered through a dream.
5. Use the actual cropped source photograph for Panel 1. Assemble it with Panels 2–4 using a deterministic image compositor so it cannot be regenerated or altered.
6. Compose four equal 2:1 horizontal panels vertically. The finished canvas must be 1:2 portrait. Prefer a practical master size such as 1600 × 3200 px, with four 1600 × 800 px panels.
7. Run the visual and technical quality checks. Correct only the failed panel when possible; do not regenerate a successful sequence unnecessarily.
8. Return the finished image and a short note naming the preserved scene anchors.

## Non-negotiable constraints

- Use exactly four equal-height panels.
- Use no borders, gaps, labels, captions, text, signatures, watermarks, or logos inside the artwork.
- Keep the original scene recognizable across all panels.
- Preserve the original light direction, spatial relationship, and emotional temperature.
- Do not reduce the method to four filters or four color grades.
- Do not introduce fantasy scenery or unrelated decorative motifs.
- Keep Panel 1 as photographic evidence; only Panels 2–4 may be reinterpreted.
- Make transitions feel progressive rather than producing four unrelated images.
- Keep three to five source-specific anchors visible across Panels 2–4, such as a roofline, horizon, path, figure, tree cluster, reflection, or light opening.
- Avoid generic “Japanese poster” decoration. Quiet design must come from the source composition, not borrowed symbols.
- Avoid embedded typography even if an image generator tries to add editorial captions.

## Quality check

Before delivery, verify:

- canvas ratio is 1:2;
- every panel is 2:1 and equal in height;
- there are exactly four panels in the required order;
- Panel 1 remains faithful to the source;
- Panels 2–4 share the source composition and light;
- the sequence clearly reads as reality, memory, abstraction, reinterpretation;
- no forbidden text, marks, borders, or gaps appear.
